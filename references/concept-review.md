# 构思筛选与视觉评审 / Concept and visual review

用于新概念探索、参考转译或弱稿诊断。已选方案的局部修改直接进入对应修正，不重新发散。以下记录可简短留在工作笔记中，不要求用户填表或逐项批准。

Use for new concepts, reference translation, or weak-output diagnosis. Selected local refinements go straight to the relevant repair. Keep notes brief; these are not user forms or approval gates.

## 构思筛选：值得画出来吗？ / Is the idea worth drawing?

在出图前，用一句话说明品牌依据、识别主体与值得探索的关系。检视这句话是否只剩「科技→连接」「家具→两块形体」「温暖→圆角」等宽泛联想；若是，回到品牌名称、实际产品、使用行为、材料或文化语境，寻找更具体的形式切入点。事实不足时标为假设，不能发明工艺、历史或用户洞察。

Before generation, briefly state the brand rationale, recognition source, and relationship worth exploring. If the idea reduces to broad associations such as technology/connection, furniture/two shapes, or warmth/rounding, revisit the name, actual product, behavior, material, or cultural context for a more useful formal starting point. Label assumptions; do not invent craft, history, or user insight.

这是一轮轻量淘汰，不要求每个 Logo 拥有行业独占寓意。熟悉的形状可以通过比例、节奏或字形处理成立；无法在文字阶段判断的点，可以保留为待验证假设再画。淘汰的是缺乏形式潜力或与品牌无关的构思，而非一切简单或常见形式。

This is a lightweight screen, not a demand for exclusive symbolism. Familiar forms may work through proportion, rhythm, or lettering. Keep promising uncertainties as hypotheses for drawing. Reject weak formal potential or poor brand fit, not simplicity itself.

## 参考进入前后两次判断 / Use references before and after

有少量已认可参考时，先实际看图，再为当前方向选择相关局部；不必重建情绪板。分清参考的角色：第三方质量与表现力基准、可转译的形式关系，或用户要求保留的自有资产。第三方参考只用于校准与转译，不沿用其可识别轮廓；自有标志按保留要求精修，不套用重新原创规则。没有已认可参考时，从现有品牌资料与资产建立暂定视觉目标，并明确这是设计判断，不强制另搜。

When a small set of approved references is available, inspect it and select relevant details; no mood board is needed. Distinguish a third-party quality benchmark, a formal relationship to translate, and a user-owned asset to preserve. Use third-party references to calibrate and translate, not to reuse recognizable contours. Refine user-owned marks within preservation requirements. If there is no approved reference, derive provisional visual targets from existing brand materials and label them as design judgment; do not require a new search.

用短句记录「看到了什么 → 准备转译什么 → 第三方参考中要避免什么」。记下具体的比例、轮廓、负空间或字体目标；只记录可见特征，不把模糊小图当精确测量。生成后回看成图与可用参考：借鉴的秩序或表现力是否出现？是否沿用了第三方可识别轮廓？若目标未出现，不因提示词写对而通过。无法看见参考时说明无法完成该对照；没有参考时按暂定视觉目标检查。

Briefly record what is visible, what to translate, and what to avoid from third-party references. Note concrete targets in proportion, contour, negative space, or type; do not derive precise measurements from unclear imagery. Compare output with available references: did the intended order or expression emerge, and did a third-party recognizable contour carry over? Correct prompt wording alone is not a pass. Report when an expected reference cannot be viewed; when none exists, check against the labeled provisional targets.

## 首轮与精修的约束强度 / Exploration versus refinement

首轮锁定文字、业务依据、识别主体、主要关系与用户硬性限制，留出轮廓和比例的探索空间。不要把一个画法写成唯一答案，也不要退回只有「高级、极简」的形容词。无需固定提示词字数或固定出图数量。

最低有效信息是「谁与谁、怎样关联、画出来检查什么」。例如字标可以探索相邻字的内部空间相互呼应、同时保持各自读名；此时无需提前定每个字腔的宽度。符号可以探索边界开合的连续与中断、检查整体轮廓能否记住；此时无需指定必须由两个矩形拼成。示例只说明关系的具体程度，不是优选方向。

For exploration, fix text, rationale, recognition source, the main relationship, and user constraints while leaving contours and proportions open. Avoid prescribing a single drawing or reverting to generic style adjectives. No fixed prompt length or output count is required.

At minimum, identify the related parts, their relationship, and the visual question to test. A wordmark might explore echoing internal spaces while preserving each character's reading, without fixing every counter width. A symbol might explore continuity and interruption in a boundary, testing whether the silhouette is memorable without prescribing two rectangles. These examples illustrate useful specificity, not preferred concepts.

例如同样探索器物与空间：未选方向时，可要求研究名称内部空间与整体节奏如何形成可记轮廓；一旦用户选中具体双块图形，才准确约束两块的位置、缺口或圆角。用户首轮已经指定双块造型时直接遵守，不擅自放宽。这个例子说明约束时机，不是推荐所有家具品牌使用字腔或双块。

For an object-and-space exploration, one possible brief asks how internal letter space and overall rhythm could create a memorable contour. Once a specific two-part mark is selected, constrain its placement, aperture, or corners precisely. Honor such details immediately if the user specified them at the outset. This illustrates timing, not a universal furniture-logo recipe.

新形态探索没有指定 SVG 时，根据需求选用图像生成、手绘草图或其他直接呈现形态的方式；不要因编码更方便就默认把设计缩成 SVG 几何拼装。图像生成不是每题必用；符合方向时可以用几何构形或现成字体。若用户明确要求 SVG，就按要求制作。位图探索只作为概念，不称为可编辑矢量；选定后再按交付需要重建路径。

For new-form exploration without an explicit SVG request, choose image generation, hand sketches, or another direct visual method suited to the task; do not default to SVG geometry just because it is easier to code. Image generation is not mandatory. Geometry and existing fonts remain valid when they fit the direction. Honor explicit SVG requests. Raster explorations are concepts, not editable vectors; reconstruct paths later if the selected deliverable requires it.

## 用画面评审性格 / Evaluate visible character

暂时遮住说明，先记录实际看到的气质和支撑它的比例、笔触、轮廓或节奏，再与品牌目标比较。允许同一画面传达多个相邻感受，不要求精确猜出预设词。若只能描述「圆润」「加了眼睛」而无法看出更具体的处理，继续审视形式；加故事不能代替修改。独立观察者反馈若未实际收集，只能称设计判断。

Hide explanatory prose, describe the perceived character and its visible basis, then compare with the brief. Related readings are acceptable; exact emotion-word matching is unnecessary. If the only observation is rounding or added eyes, inspect the treatment more closely rather than extending the story. Without actual independent observer feedback, this remains design judgment.

## 从实际成图筛选推荐 / Screen actual artwork for recommendations

把推荐稿和探索稿分开。默认只推荐 2–3 个经视觉筛选的方向；用户指定数量时照给该数量，并逐个标明探索中、可继续精修或推荐。某稿若只是默认字体加普通排列、通用节点图或扫描框，即使释义贴合品牌，也仍是探索稿；只有能指出可见的比例、轮廓、留白、字形或图文关系，并说明它解决了什么，才有推荐依据。不要为凑足默认数量把弱稿包装成推荐；如果都未通过，就如实标注并保留最值得继续验证的方向。

Separate recommendations from explorations. Normally recommend only 2–3 visually screened directions. When the user specifies a count, deliver exactly that count and label each as exploring, suitable for further refinement, or recommended. A default font in ordinary layout, a generic node graphic, or a scan frame remains an exploration even if its rationale sounds on-brief. Recommend it only when visible proportion, contour, negative space, lettering, or a mark-to-type relationship can be identified and tied to a concrete design need. Do not pad recommendations; if none passes, say so and identify the most useful direction to test further.

## 保留失败证据，选择下一步 / Keep evidence and choose the next step

对真正影响决定的淘汰稿，保留实际图像或可访问路径，简记「目标 → 可见问题 → 保留项 → 下一步」。精修前说清本轮要改变的一个主要问题；精修后记录实际变化、是否改善，以及保留项。针对一个问题通常做一至两轮聚焦修正；连续没有可见改善时停止重复抽图，调整为更可控的方法或报告未解决的限制。只记录本轮有用的案例，不自动写入长期记忆。分清实测结果与假设，不靠打分或文件校验宣称审美提升。

For consequential rejected drafts, retain the actual image or accessible path and briefly record intent, visible failure, viable parts, and next action. Before refinement, name one main issue to change; afterward, record the visible change, whether it improved, and what remains. Usually limit one issue to one or two focused passes. If there is no visible improvement, stop resampling and switch to a more controllable method or report the unresolved limit. Keep only useful task-local cases; do not write long-term memory automatically. Separate observations from hypotheses; scores or file checks do not prove aesthetic improvement.

本次维护的已观察案例（2026-10-02）：间物 C1、C2 在展示尺寸下可读，右侧均为相近的双块留缝结构。保留字符准确性的改善；下一步重新检查构思与过早锁定双块的提示词，而非继续只调圆角。这两张图只能说明该次探索的局限，不能证明双块形式普遍无效，也未证明具体提示词是唯一原因。原始图像与提示词随本次维护交付记录保存，不作为后续所有品牌的默认参考。

Observed maintenance case (2026-10-02): Jianwu C1 and C2 were readable at presentation size, while both right-hand marks used similar two-part gap structures. Preserve the reading improvement; next revisit the concept and early shape prescription rather than merely adjusting corners. This case neither invalidates two-part forms in general nor proves prompting was the sole cause. Images and prompts remain in the maintenance delivery record, not the default reference for every future brand.
