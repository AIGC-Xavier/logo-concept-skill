# 品牌表达与系统延展

本页提供科技抽象与情绪表达两种可选路径。按当前品牌和任务选择适用部分，遵守已定字体、符号及局部修改范围；每个形式假设都需要通过实际成图检查。

## 科技抽象构形

从具体产品、结构或品牌事实中寻找可见关系，再决定是否使用切割、重复、旋转、模块或曲线。它们是可选手法，不是清单；科技感不要求几何图形、无衬线或低饱和。先检查图形与字标的识别、比例和实际应用，颜色与渐变按品牌和场景选择。

新概念可沿「品牌事实 → 关系 → 构形 → 识别检查」推进。例如多源信息汇合，可以研究不同路径如何汇入一个清晰整体，而非默认画网络节点；模块协作，可以研究同一规则下的独立与衔接，而非随意堆方块。同一品牌事实可以产生多种构形，需比较实际成图的识别度与品牌适配。

一次选定一种主要组织关系，统一转角、间隙或重复节奏中真正需要一致的部分，允许为视觉重心作光学校正。图形与字标并置时比较两者的视觉重量、间隙和主次。去掉渐变后检查轮廓与关键空隙，在目标尺寸确认细条和切口仍可见；用颜色强化层级，不能靠发光或材质救回模糊结构。

## 情绪化有机品牌

把情绪词转成可见的比例、重心、开合、轮廓或节奏；抽象故事不能补救不清楚的图形。区分身份中稳定不变的特征与可变化的姿态。先在单色平面和目标尺寸检查核心标识，再按实际任务需要做角色、插画、渐变或组合延展。

**情绪需要落到行为，再落到形态。** 从品牌事实选少量有区分度的性格词，说明它在用户体验中体现为何种行为，再提出可见的形式假设。例如「好奇」可对应探看或接近，探索偏移重心或开放方向；「温暖」可对应接纳或陪伴，探索包容的空间关系与柔和节奏。这些只是待验证的设计假设，并非固定情绪符号表。不要把每个词画成一个元素后相加；一组形式可以同时表达多种感受。

有角色需求时，先写清少量身份特征及允许的变化范围。例如轮廓节奏、关键部位比例和部位关系可以保持稳定，姿态、方向、局部表情可以随情境变化。选定能代表当前品牌的识别特征，并检查它在不同姿态中是否仍然清楚。若只有文字需求，性格可以由字形与字间节奏承担。

| 层级 | 承担的任务 | 检查方式 |
| --- | --- | --- |
| 核心 Logo / 图标 | 稳定识别与读名 | 单色、反白、目标尺寸；去掉质感仍有清楚身份 |
| 简化角色 / 表情 | 互动、反馈与情境变化 | 多种姿态放在一起仍像同一角色；产品状态含义清楚 |
| 复杂插画 / 材质表现 | 叙事、氛围与传播 | 继承已定身份特征；不把场景细节塞回主标 |

仅执行本轮需要的层级。角色嵌入字标时，保留字母的读音与阅读线索；无法读名就分开使用。延展时比较同一套形态在平面、动态或材质表达中的连续性。安全空间以自身标识的比例、细节和实际碰撞测试确定；复杂背景上先检查对比与干扰，再决定反白或承托区域。

性格词数量、角色部件、配色、材质与留白比例根据品牌和应用决定。若用户已指定字体、符号或只改局部，沿用该边界。

## 行为用例

- 科技品牌有明确的结构依据时可探索抽象关系；不强制几何。
- 情绪品牌可用比例或节奏传达性格；不强制吉祥物。
- 用户只要求调整字间距时，只调间距并保留既定字体与符号，不重做品牌。
